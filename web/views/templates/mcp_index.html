MCP

The Model Context Protocol endpoint lets a language model query this archive directly, at /mcp. Two things gate it: which groups it may read, and which tokens may ask.

Exposed groups

The allowlist. Nothing is readable through MCP until a group is added here — private groups and direct messages are never exposed.

Access tokens

Bearer tokens for MCP clients. Shown once at mint time and stored only as a hash, so a lost token is replaced rather than recovered.

Connecting a client

Point an MCP client at https://<this-host>/mcp and give it the token as a bearer credential:

Authorization: Bearer tgmcp_…

The endpoint is read-only. It can list exposed groups, read and search their messages, and look up users; it cannot write anything back.
